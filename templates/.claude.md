## Analysis Instructions

### File Analysis
```
ANALYZE_FILES:
- Include: "*.php", "*.py", "src/**/*", "app/**/*"

- Max File Size: 500 lines (suggest splitting if larger for new files only)
- Scan Depth: Recursive
- Legacy Protection: Do not refactor existing large files
```

### Function Analysis
```
ANALYZE_FUNCTIONS:
- Extract all function signatures with complete metadata
- Check input/output type declarations
- Identify missing documentation (docblocks/docstrings)
- Calculate complexity metrics (cyclomatic complexity)
- Check error handling patterns (try-catch blocks)
- Verify naming conventions follow project standards
- Track function origin (legacy/user/claude-generated)
```

```

- ALL CODE: Functions must have appropriate error handling where needed
- ALL CODE: Functions must include logging where appropriate
- LEGACY CODE: Apply relaxed rules, no forced refactoring
```

### Task Priorities
